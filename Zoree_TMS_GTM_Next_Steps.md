# Zoree TMS — Go-To-Market Next Steps

Sequenced checklist · Prepared June 28, 2026

**Starting point:** No discoverable footprint on LinkedIn or the open web; brand name collides with unrelated entities (ZORA, Zorie, Zore's). Content assets already exist — marketing site, three email templates, two promo videos, a 3-min demo with voiceover. So this is a **launch + distribution** plan, not a content-creation one.

**Strategy:** Lead with LinkedIn for reach; stand up the SEO-ready site in parallel as the place demand lands and converts.

Tags — **Effort:** S = <½ day · M = ½–2 days · L = >2 days. **Priority:** P0 = do first.

---

## Phase 1 — Claim the brand (this week) · P0

- [ ] Create the LinkedIn **company page** — logo, banner, tagline (use Section 5 copy from the channel analysis), About section, website link, Industry = Transportation/Logistics. *(S)*
- [ ] Publish the **website live** with "Zoree TMS" in the title tag, H1, and meta description so the brand ranks #1 for itself. Use the hero + meta copy already written. *(S–M)*
- [ ] Register **Google Search Console** + verify the domain; submit sitemap. *(S)*
- [ ] Secure matching handles / reserve the name on the directories you'll use later (G2, Capterra, Gartner Peer Insights) even before reviews exist. *(S)*

## Phase 2 — Start distribution (week 1–2) · P0

- [ ] Begin **LinkedIn posting cadence: 2–3 posts/week**. Queue the three ready-made posts (problem/solve, audit-trail value, insight) to start. *(S, recurring)*
- [ ] Post the **promo video + 3-min demo** natively to LinkedIn (native upload, not a link — far better reach). *(S)*
- [ ] Wire up the **email templates** (welcome, demo-invite, feature-spotlight) to a sending tool and a "Book a demo" form on the site. *(M)*
- [ ] Add a single, obvious **demo CTA** on every site page pointing to a real calendar/booking link. *(S)*

## Phase 3 — Build proof & third-party signal (week 2–4) · P1

- [ ] List Zoree TMS on **G2, Capterra, Gartner Peer Insights** — these rank for category terms and create branded backlinks. *(M)*
- [ ] Stand up **SEO landing pages** targeting "transportation management system," "TMS for 3PLs / brokers / shippers," and 2–3 use-case pages. *(L)*
- [ ] Collect **2–3 early reviews / quotes** from any pilot or demo users to seed social proof. *(M, dependency: have demo users)*

## Phase 4 — Measure & iterate (end of month, recurring) · P1

- [ ] Set a **monthly tracking baseline**: LinkedIn page views / followers / post impressions; Search Console impressions / clicks / branded-term position. *(S)*
- [ ] Re-evaluate the **LinkedIn vs. web split** once 30 days of data exists; double down where conversion is real. *(S)*

---

## Open decisions to resolve first

- **Name collision:** decide whether to always brand as "Zoree TMS" (not just "Zoree") in every title and handle to fight the ZORA/Zorie/Zore's ambiguity. Recommended: yes, consistently.
- **Demo booking:** which calendar/CRM the "Book a demo" CTA points to — this gates Phases 2–3.
- **Who owns the LinkedIn page** and posting (founder profile reach usually beats a cold company page — consider posting from your personal profile too).

### Production notes
- Ratio of real UI to AI B-roll ≈ 45% / 40% / 15% GFX — the product stays the hero.
- Every UI shot moves (push, pan, crop) — zero static screens.
- The CTA explicitly routes viewers to the existing demo video; the trailer never replaces it.
- All UI sources harvested into `assets/` (see `assets/assets-manifest.md`): 8 real screen-recording clips + 8 stills upscaled to 4K. Scenes 6A/7A use Ken Burns on the 4K Live Tracking / Analytics stills; optional fresh screen recordings would upgrade them to true motion but are not blocking.

4 · What changed (and why)

Global

  • Drop universal ALL CAPS. Today every label, button, and badge is uppercased. It reads loud and dates the UI. Reserve uppercase for tiny eyebrow labels (10.5px) only — body text stays sentence-case.
  • Quieter chrome, louder content. Borders move from #E2E8F0 to a softer #EDEFF3; surfaces shift to #F7F8FA. Headers and values get the contrast instead of the boxes.
  • Tighter type scale. 28→22px page titles, 30→26px KPI numbers. Same hierarchy, less shouting on small screens.
  • Single brand blue used sparingly. Today blue lives on every chip, header, and link. Mockup keeps blue for the primary CTA, focus rings, and active sidebar item only — everything else is monochrome.
  • Real focus states. 3px brand-soft ring on inputs replaces the current border-only treatment.

Sidebar & topbar

  • Sidebar search with ⌘K — discoverability beats scroll-and-scan in a 30-module nav.
  • Inline counts (orders 142, exceptions 3) replace the existing pill badges floating off to the right; counts stay on the row, hot ones turn red.
  • Active state uses a 3px left rail in brand color + soft tinted background, instead of a plain background highlight.
  • Topbar breadcrumbs: today every page just shows its own title. With 35 pages, breadcrumbs orient you without taking real estate.

Home / dashboard

  • Greeting + summary line instead of a dry page title — sets context for the day in one sentence.
  • KPI cards with sparklines — today’s KPIs are a single number with a delta. Sparklines give the trend at a glance without a separate chart.
  • Module cards reduce per-card padding (24→16px) and use a clean icon tile instead of an emoji square — emojis render inconsistently across OS versions.
  • Insights + activity columns: same content as today, but insights now use a colored lead bar (blue/amber/red) instead of full-width tinted backgrounds, which were competing with the rest of the page for attention.

Orders list

  • Status chips double as filters and counters. Today the stat-grid and chip-row are separate; combining them saves vertical space and makes the page feel more like Linear/Retool.
  • Monospace IDs (ORD-394206) so the eye locks onto the column. Tabular numerics for weights/costs keep right-alignment clean.
  • Row hover uses surface-2, not #DBEAFE — the current “electric blue” hover is jarring on long lists; the selected row keeps brand-soft so selection still pops.
  • Header cells drop height:44px in favor of natural padding, and lose letter-spacing:.06em for a calmer look. Sort affordance moves to a hover-only chevron.

Pack Order modal (the big one)

  • Read-only fields stop being inputs. Today ORDER, CUSTOMER, SOURCE etc. are styled as bordered boxes that look editable. They become a calm 3×3 facts grid with eyebrow labels — same density, less visual noise.
  • Stage rail turns the “Stage 7 → 8” pill into actual progress: 7 green segments + 1 active. Reusable across all stage modals (1–8).
  • Header gets a brand mark + eyebrow: the dark navy header bar from today is heavy on a small modal; a light header with brand-tinted icon and small shipment ID eyebrow works better at this size.
  • Inputs gain real labels — “Carton count” instead of CARTON COUNT in caps, units shown as suffixes inside the input (cartons, lbs, pallets) so users don’t need to read the label to know what unit they’re typing.
  • Footer gets context: who last updated and when, plus a Save-draft option in case ops needs to step away mid-pack.
